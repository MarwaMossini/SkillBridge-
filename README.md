# SkillBridge

An academic recruitment and career guidance website for students, employers, and career counselors.

## Academic Context
- Course: Software Engineering (CSCI4004), Asian University for Women (AUW).
- Semester: Summer 2026.
- Team: Three students.

## My Contribution
I researched related recruitment websites and compared their features with our project. I also created data flow diagrams (DFDs) and wrote use case descriptions to explain the system's workflows and user interactions.

## Features
- Browse and filter jobs and internships.
- Create student, employer, and career counselor accounts.
- Submit and track applications.
- Upload resumes and explore rule-based job recommendations and skill-gap analysis.
- Manage opportunities, users, and counseling sessions.

## Technologies
PHP, MySQL, HTML, CSS, JavaScript, and XAMPP.

## Local Setup
1. Extract the project and copy `skilledbridge` into `C:\xampp\htdocs\`.
2. Start Apache and MySQL in XAMPP.
3. Open http://localhost/phpmyadmin/ and create a database named `skilledbridge`.
4. Select the database and import `skilledbridge/sql/skilledbridge.sql`.
5. Open http://localhost/skilledbridge/.

## Project Status
An academic prototype for local demonstration. Recommendation features use educational rule-based scoring. Update expired sample job deadlines to display opportunities in searches.

Further testing and development can help address the current limitations.
